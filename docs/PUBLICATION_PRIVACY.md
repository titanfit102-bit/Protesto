# Publication privacy gate — development-only
The original case title and description are confidential inputs. A reviewer must create and explicitly acknowledge a separate public title, description and URL before publishing. The public cases API **only** selects approved public fields; older published database records without approved text are withheld rather than exposing the raw narrative.
Queries and fragments in public URLs are prohibited, and the URL must match an accepted source. This is a human redaction/approval workflow, **not** automated personal-data detection or legal compliance. Approved text can still be unsafe; a qualified reviewer must check it. Separate source-list and action routes remain subject to independent review. No real reports may be published at this stage.
