# Reviewer MFA — staged pilot control
Migration 010 adds encrypted per-reviewer TOTP secrets and monotonically increasing replay counters. TOTP is RFC 6238 SHA-1/6 digits/30 seconds (±one step), verified under a PostgreSQL row lock and updated atomically with session issuance. The one-time code is never persisted. The secret is encrypted at rest using a separately provisioned **32-byte base64url PROTESTO_MFA_KEY**. The key must NOT be committed, re-used for other environments or output in logs.
Operator enrollment is manual via `node tools/enroll-reviewer-mfa.mjs reviewer@example.org` with DATABASE_URL and PROTESTO_MFA_KEY provided securely. The one-time otpauth URI printed locally must be entered into a trusted authenticator and never shared.
Enrollment is intentionally opt-in until every reviewer is migrated. Missing MFA on unenrolled accounts remains a **P0 risk**, and there is **no account recovery or key rotation procedure**. Do not launch production or enable real reporter enrollment until those are implemented and approved.
